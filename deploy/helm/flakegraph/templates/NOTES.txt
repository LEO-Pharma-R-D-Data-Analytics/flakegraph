Submit from a trusted client that can reach the same PostgreSQL service:
  flakegraph distributed submit --config /path/to/config.yaml

Inspect progress:
  flakegraph distributed status --run-id <run-id> --config /path/to/config.yaml

{{- if .Values.modelServing.enabled }}

Local model serving is enabled. Check replicas and the served model:
  kubectl -n {{ .Release.Namespace }} rollout status statefulset/{{ include "flakegraph.modelServingName" . }} --timeout=60m

Every engine pod runs behind an authenticating sidecar. Map bearer keys to
consumer classes in Secret {{ .Values.modelServing.sidecar.keySecret.name }}, key
{{ .Values.modelServing.sidecar.keySecret.key }}; an unlisted key is refused and
an unlisted class is served last.
{{- else }}

Local model serving is disabled. Configure external provider endpoints and models
in the mounted FlakeGraph config, map credentials through providerSecret.env, or
enable modelServing in a private values file.
{{- end }}
